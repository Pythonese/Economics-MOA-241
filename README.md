### **Лекция 1. Введение в экономику**

**Предмет экономики**

| **Предмет экономики** |
| :--- |
| **Economy** - это реальная экономика или «народное хозяйство». При данном подходе изучают основные виды деятельности реальной экономики (металлургия, строительство, машиностроение и т.д.). |
| **Изучает** - основные виды деятельности реальной экономики. |
| **Economics** - это «экономическая теория», теоретическая экономика — общественная наука, которая изучает проблему выбора для достижения поставленной цели в условиях ограниченности ресурсов. |

| **Предмет экономической теории** - ресурсы и экономические отношения, которые способны удовлетворить запросы потребителей. |
| **К какой области знаний относится экономика?** |
| **1. Экономика** - общественная наука, изучает человека, общество и тесно соприкасается с другими науками. У нее есть признаки и естественных, и формальных наук. |
| **Тесно соприкасается с** - социологией, юриспруденцией, психологией, географией, статистикой, математикой. |
| **Пересечения экономики и юриспруденции** - наблюдаются в гражданском праве. |
| **Пересечения экономики и социологии** - происходят в маркетинговых исследованиях различных социальных групп. |
| **Пересечение экономики и психологии** - наблюдается при анализе импульсивных покупок и в целом при осуществлении финансовых трат. |
| **2. Экономика – это** - наука, у которой есть сходства с естественными науками, особенно с географией. |
| **Пересечение экономики и географии** – отражается в выборе оптимального размещения производительных сил, а именно промышленных производств. |
| В естественных науках распространенный метод получения информации - это исследование, наблюдение и опыты. |
| **В экономике** - ставить опыты сложно, иногда эксперименты просто невозможно провести или их невозможно повторить. Но в некоторых случаях наблюдения и даже эксперименты возможны, например, в виртуальной экономике. |

| **Пересечение экономики и статистики** - учет численности населения государством для закрытия их базовых потребностей. |
| **Пересечение экономики и математики** - можно наблюдать повсеместно от расчета скидок в супермаркетах до построения экономико-математических моделей. |
| **Модель - это** - упрощенное или абстрактное представление реальной системы или процесса, которое используется для анализа, понимания или прогнозирования ее поведения и результатов. |
| **Наиболее известные модели в экономике:** - модель Маршалла (крест Маршалла, спрос и предложение), кривая производственных возможностей, модель кругооборота. |

**Модель** - это некое упрощенное описание реального объекта, работать с которым проще, безопаснее, чем работать с самим исходным объектом.

**В модели при упрощении действительности экономисты** - делают оговорку «при прочих равных условиях» и концентрируют свое внимание на наиболее важных для понимания проблем экономики факторах.

### **Лекция 2. Основные понятия экономики**

**Потребность и блага**

| **Потребность и блага** |
| :--- |
| **Потребность** - это необходимость в каких-либо благах для поддержания жизнедеятельности и развития человека, а также общества в целом. Иными словами, это чувство неудовлетворенности, когда вам чего-то не хватает. |
| **Благо** - это средство удовлетворения потребностей человека. |
| **Экономические блага** - это ограниченные средства, пригодные для удовлетворения потребностей человека в форме товаров или услуг. |
| **Свободные блага** - это блага, которые люди получают от природы (неэкономические блага). |
| **Все блага делятся на товары и услуги:** |
| **Товары** - материальны. Их можно потрогать. Товары нужно сначала произвести, а потом использовать. |
| **Услуги** - нематериальны. Потребляются в момент их производства. |
| **В современном мире большая часть производимых благ** - это именно услуги. |
| **Грань между экономическим и свободным благом** - не абсолютна. Благо становится экономическим, если для его производства требуются ресурсы (факторы производства). |
| **П** Воздух на улице - свободное благо. |
| **П** Воздух на подводной лодке - экономическое благо. |
| **П** Вода в роднике - свободное благо. |
| **П** Бутилированная вода в магазине - экономическое благо. |

**Проблема экономического выбора**

| **Экономический выбор** - это решения людей о наилучшем использовании имеющихся ограниченных ресурсов. |
| :--- |
| **При выборе альтернативного варианта обычно руководствуются двумя принципами:** |
| **Принцип максимума —** получить наибольшую выгоду, используя имеющиеся ограниченные ресурсы. |
| **Принцип минимума —** с минимальными затратами достичь определённого заданного результата. |
| **Проблема выбора стоит перед всеми субъектами экономики** (домашним хозяйством, фирмой, государством). |

**Альтернативные издержки**

| **Альтернативные издержки** — это затраты, связанные с упущенной выгодой от лучшей альтернативы, которая была бы выбрана, если бы не было принято текущее решение. |

| **Расчет:** |
| Альтернативные издержки аренды = 20000*12 = 240 000 рублей за год |

**Задача**

Николай учится на платном отделении университета в родном городе. Он решил вести список своих ежемесячных трат. Вот, что он получил в сентябре:
- 40000 руб. – оплата обучения в университете
- 6000 руб. – на книги и тетради для учебы
- 2000 руб. – на проезд до университета и домой
- 7000 руб. – на покупку продуктов питания (питается Николай дома)
- 5000 руб. – на оплату коммунальных платежей за квартиру, в которой живет Николай. Также известно, что если бы не учеба, то Николай работал бы финансистом в банке за 35000 руб./мес.

Определите, какие из перечисленных расходов Николая связаны исключительно с решением Николая учиться в университете, а какие он нес бы в любом случае?
Каковы суммарные ежемесячные альтернативные издержки решения Николая учиться в университете?

**Условия задачи:**
Зарплата – +35000 руб.
Расходы:
оплата обучения в университете - 40000 руб.
книги и тетради для учебы - 6000 руб.
проезд до университета и домой - 2000 руб.
продукты питания (питается Николай дома) - 7000 руб.
оплата коммунальных платежей за квартиру, в которой живет Николай - 5000 руб.

**Решение:**
Постоянные затраты – 7000 + 5000 = 12000 руб.
Альтернатива 1 (работа) = 35000 - 12000 = +23000 руб. (остаток дохода)
Альтернатива 2 (учеба) = -40000 - 6000 - 2000 = -48000 руб.
**Ответ:** Альтернативные издержки Николая учиться в университете составят 48000 + 23000 = **71000 руб.**

**Задание 1.** После окончания Лицея Таня хочет жить отдельно от родителей и перед ней стоит выбор: поступить на учебу на платное отделение экономического факультета МГУ (и продолжить жить с родителями) или поработать несколько лет секретарем в нефтегазовой компании (и начать жить отдельно). Посчитайте альтернативные издержки учебы на экономе, если:
- Плата за учебу - 140 тыс. руб/год;
- Оплата снимаемой квартиры – 20 тыс. руб/мес;
- Расходы на питание – 15 тыс. руб/мес;
- Транспортные расходы – 2 тыс. руб/мес;
- Расходы на одежду – 40 тыс. руб/год;
- Расходы на учебники – 5 тыс. руб./год
- З/п секретаря – 50 тыс. руб. /месяц.

**Условия задачи:**
Доход при работе = 50 * 12 = 600 тыс. руб/год.
Расходы при учебе: 140 (учеба) + 5 (учебники) = 145 тыс. руб/год.
Расходы, которые будут в любом случае (питание, одежда): 15*12 + 40 = 220 тыс. руб/год.
Расходы, которые возникнут только при работе (аренда, транспорт): 20*12 + 2*12 = 264 тыс. руб/год.

**Решение:**
1. **Альтернатива 1 (работа):** Доход = 600 тыс. руб. Расходы = 220 (общие) + 264 (доп. на работу) = 484 тыс. руб. Чистый доход = 600 - 484 = 116 тыс. руб.
2. **Альтернатива 2 (учеба):** Доход = 0. Расходы = 220 (общие) + 145 (на учебу) = 365 тыс. руб. Чистый доход = -365 тыс. руб.
Альтернативные издержки = Упущенная выгода от лучшей альтернативы (работа) + прямые затраты на учебу.
Более простой способ: Альтернативные издержки = (З/п за год - доп. расходы на работу) + прямые расходы на учебу = (600 - 264) + 145 = 336 + 145 = 481 тыс. руб.
**Ответ:** 481 тыс. руб/год.

| **Строится в система координат, в которой по осям отражается возможное производства различных товаров** |

| **Кривая производственных возможностей как модель экономического выбора** |
| :--- |

| **Абсолютные и относительные преимущества как основа обмена** |
| :--- |
| Международная специализация основана на производительных преимуществах той или иной страны, которые проявляются в двух формах: **абсолютные и относительные преимущества**. |
| **Принцип абсолютного преимущества (А. Смит):** в каждой стране существуют особые условия и ресурсы, дающие ей возможность производить определенные товары с меньшими издержками (или производить в единицу времени большее количество данных товаров). |
| **Абсолютное преимущество** - способность предпринимателя, компании или страны произвести большее количество качественного продукта, используя одинаковое, определённое количество ресурсов. |
| **Факторы абсолютного преимущества:** 1) благоприятные природные и климатические условия, 2) дешевое и легкодоступное сырье. |
| **Принцип относительного преимущества (Д. Рикардо):** В стране всегда найдется товар, производство которого будет относительно более дешевым, чем производство остальных товаров при существующем соотношении издержек в разных странах. |

### **Лекция 4. Модель принятия экономических решений**

**Система предпосылок. Homo economicus. Критика концепции homo economicus. Экономический институционализм. Поведенческая экономика. Поведенческие эффекты**

| **Моделирование** - это использование упрощенных аналогов вместо реальных объектов. |
| :--- |
| **Модели** - это основной инструмент экономической теории (модели рынка, поведения потребителей, фирм и т.д.). |
| В основе этих моделей лежат общие идеи – представления о том, как люди, фирмы и другие участники принимают решения, которые в экономической теории получили название **система предпосылок**. Экономисты эту систему предпосылок называют **моделью поведения человека – homo economicus**. |

**Система предпосылок**

| **Homo economicus Человек экономический** |
| :--- |
| Модель «компетентного эгоиста» сформулировал **Адам Смит**, где указал, что человек в своем поведение действует: (1) индивидуально, (2) компетентно и (3) способен к рациональному выбору. |
| Homo economicus (с лат. — «человек экономический», «человек рациональный») ввел в оборот **Джон Стюарт Милль**. |
| **Homo economicus** - человек, действующий разумно и рационально, всегда стремящийся к максимизации получаемой прибыли и делающий выбор из-за значения экономических результатов этого выбора. |
| **Модель «экономического человека»** - это фундаментальная словесно-описательная модель экономического поведения человека. |
| 1. Человек-индивидуалист, он стремится наиболее полно удовлетворить свои потребности. |
| 2. Человек обладает всей полнотой информации о ценностях ресурсов, благ и о возможных последствиях выбора. |
| 3. Человек способен осуществлять рациональный выбор, просчитывая все возможные варианты и последствия их принятия. |
| **Homo economicus** - это некий абстрактный рациональный эгоист, действующий в собственных интересах и стремящийся к наибольшей выгоде. |
| **Полезность объекта** - его способность удовлетворять ту или иную человеческую потребность. |
| **Рациональность** – это способность человека принимать правильное решение в свою пользу. |
| **Рациональное экономическое поведение** – поведение, направленное на получение максимального результата при минимальных затратах в условиях ограниченности возможностей и ресурсов. |
| **Этапы принятия решений рационального человека:** 1. Получение экономических данных. 2. Перевод данных в релевантную информацию. 3. Контролируемое мышление. 4. Оптимальное поведение в реализации своего выбора. |

**Критика концепции homo economicus**

| В действительности наблюдаются отклонения от рационального поведения. В экономических науках человек экономический определяется как гипотетический человек, так как в действительности человек не ведет себя рационально, а его решения не являются основанными исключительно на экономическом расчёте. |
| :--- |
| В экономической теории следует учитывать отсутствие рационализма человека в принятии решений. |
| **Расширенная модель принятия решений учитывает следующие аспекты:** |
| 1. Получение экономических данных при разнообразных культурных установках, эмоциях, контексте. |
| 2. Релевантная информация является не единственно значимым фактором. |
| 3. У людей присутствует ограниченность мышления (возраст, психические атаки, стресс, культурное наследие, религиозные установки и др.). |
| 4. Отклонение поведения от намеченного плана. |
| **Концепция homo economicus** - Люди не всегда рациональны. Они не всегда последовательно преследуют свои интересы и даже сами интересы могут меняться в разные моменты времени. |
| **Причины иррационального поведения индивида объясняются в** (1) экономическом институционализме, (2) поведенческой экономике. |

**Экономический институционализм**

| **Институты** - это нормы, ограничения и принципы поведения («правила игры»), которым следуют люди в своих действиях. |
| :--- |
| **Представители направления** - Рональд Коуз, Оливер Уильямсон, Дуглас Норт. |
| **Пример.** В пищевом потребление обычно люди руководствуются климатом, доступностью и ценой товара. Однако, в регионах с преобладанием населения, исповедующего ислам, данный «рациональный» подход не работает, так как нормы ислама запрещают употребление свинины. |

**Поведенческая экономика**

| **Представители направления** - Дэниэл Канеман, Амос Тверски, Дэн Ариели. |
| :--- |
| **Поведенческие эффекты** - особенности поведения реальных людей, далеких от расчетливой рациональности, подчиняющихся нерациональным законам. |
| 1. **Эффект неприятие потерь (Loss aversion)** - люди, склонные к излишнему риску, понимая, что могут потерять деньги, продолжают играть, надеясь отыграться. |
| 2. **Эмпатия** - в эксперименте с разделением денег второй игрок может отказаться от несправедливо маленькой суммы, даже если рационально должен был бы взять хоть что-то. |
| 3. **Влияние контекста на принятие решений** - решение покупателя может зависеть от обстоятельств (например, покупка трех арбузов при наличии таблички «три арбуза — 10 рублей»). |
| 4. **«Смещение к настоящему» (present bias)** - неправильная оценка ценности или вреда будущих событий, акцент на получении выгоды в настоящем. |
| 5. **Эффект владения (Endowment effect)** - люди ценят то, чем владеют, выше, чем то, чем не владеют. |
| 6. **Социальные предпочтения (Social Preferences)** - люди могут действовать альтруистично или руководствоваться чувством справедливости. |
| 7. **Искажения, связанные с инерцией или статус-кво** - люди склонны сохранять текущее положение вещей. |

**Задание 1.** Приведите примеры выбора и поведения человека, обусловленные правилами институциональной экономики.

### **Лекция 6. Кругооборот экономических благ, ресурсов и доходов как простейшая модель рыночной системы**

**Экономические агенты. Модель кругооборота экономических благ, ресурсов и доходов. Эффект мультипликации. Детализация модели. Значимость модели**

**Экономические агенты** - субъекты экономических отношений, принимающие участие в производстве, распределении, обмене и потреблении экономических благ.

| **Открытая экономика** - тип экономики, при котором наблюдается её интеграция в систему мировых хозяйственных связей, обеспечивающих свободный экспорт и импорт товаров и услуг между странами. |
| :--- |
| **Закрытая экономика** — это экономика страны, которая не торгует и не участвует в других финансовых обменах с какой-либо другой страной. |
| Полностью открытых либерализованных экономик в мире почти не существует. Поэтому говорят о более или менее открытых экономиках. |
| В открытой экономике выделяют четыре макроэкономических агента: |
| **Домохозяйства** - домашние хозяйства, а именно индивиды и их семьи. |
| **Фирмы** — это организации в виде фабрик, ферм, шахт, магазинов, которые выполняют несколько функций по производству и распределению товаров и услуг. |
| **Государство** — агент, состоящий из государственных учреждений, задача которого состоит в регулировании экономики. |
| **Иностранный сектор** — все остальные государства и иностранные компании. |

**Функции и цели экономических агентов**

| Функции | Цели |
| :--- | :--- |
| **Домохозяйства:** Потребление | Максимизация полезности |
| **Фирмы:** Производство | Максимизация прибыли |
| **Государство:** Обеспечение общественных потребностей и безопасности | Рост богатства нации |
| **Иностранный сектор:** Обмен товарами | Наполнение экономики необходимым и ресурсами |

**Модель кругооборота экономических благ, ресурсов и доходов** - показывает функционирование экономики как единого организма. Это достигается благодаря тому, что экономические агенты взаимодействуют между собой посредством системы рынков:
- рынки товаров и услуг, иначе рынки благ;
- рынки факторов производства (труда, капитала, земли и др.)

**Движение против часовой стрелки, внутренний контур (доходы).**
Человек, покупая колбасу, платит деньги в магазине. Для него эти деньги являются расходом. Эти деньги получает производитель колбасы. И для него эти деньги являются выручкой – доходом. Соответственно, из этой выручки производитель колбасы платит, к примеру, заработную плату человеку. Теперь деньги превратились в расходы фирмы и доход работника. Человек на эту заработную плату покупает новую колбасу.

Таким образом, у нас происходит кругооборот:
**по внешнему контуру** - **благ** (колбаса) и **ресурсов** (труд);
**по внутреннему контуру** - **доходов** (заработная плата работника и выручка фирмы) и **расходов** (расходы работника на приобретение колбасы и расходы фирмы на выплату заработной платы работнику).

**Суть эффекта мультипликации** - если субъект экономики воздержался от расходов, то эти деньги не входят в кругооборот доходов и расходов и лишают доходов других производителей, потребителей.
**Мультипликативный эффект** — это процесс воздействия изменяемой (входной) величины на результирующую (выходную) на протяжении нескольких циклов развития системы, имеющий затухающий характер.

**Детализация модели.**

Домохозяйства получают **доходы** и направляют их на (1) **потребление** и (2) **сбережения**.
Сбережения аккумулируются в **финансовой системе** (банки, фондовый рынок).
Финансовые институты (ком. банки) выдают **кредиты** фирмам и домохозяйствам.
Фирмы осуществляют вложения **инвестиционные расходы**.
**Финансовый рынок** - это посредник между теми, у кого есть лишние деньги – сбережения и теми, кому они нужны в настоящий момент, для инвестирования в производство, оборудование, транспорт и др.

**Значимость модели**
1. Позволяет объяснить причины кризисов в экономике. В рыночной экономике нет единого центра, который бы управлял всеми процессами. Сбои в одном звене по цепочке затрагивают всех субъектов.
2. Обладает возможностью регулирования экономики с помощью вливаний денежных средств и наоборот с помощью их изъятий. Помочь фирме может финансовый сектор (ссудить деньгами) или государство (льготы).

**Задание 1. Чем различаются кругообороты товаров, услуг, денег и ресурсов в закрытой и открытой экономиках? В рыночной и смешанной экономиках?**
**В закрытой** – отсутствует иностранный сектор, нет экспорта и импорта.
**В открытой** – присутствует иностранный сектор, добавляются потоки экспорта и импорта товаров и капитала.
**В рыночной** – государство минимально вмешивается в экономику.
**В смешанной** - государство активно участвует в перераспределении ресурсов через налоги, субсидии, трансферты и государственные закупки.

**Задание 2. Какие свойства модели можно выделить в модели кругооборота? Какие используются допущения при построении модели кругооборота экономических благ, ресурсов и доходов?**
**Свойства модели:** упрощение, абстрагирование, наглядность, возможность анализа взаимосвязей.
**Допущения модели:** цены неизменны, рассматривается закрытая экономика (в базовой модели), отсутствует государство (в простейшей модели), домохозяйства тратят весь доход на потребление.

### **Лекция 7. Рынок и экономические основы его функционирования**

**Рыночный обмен. Функции, требования к материалу и виды денег. Номинальные и реальные экономические величины**

**Рыночный обмен**

| **Рынок** - это и небольшой базар возле дома, и национальный рынок каких-либо товаров, и глобальные рынки. |
| :--- |
| **Общая черта всех рынков (независимо от масштаба, типа продаваемого товара)** – взаимодействие двух типов участников. |
| **Покупатели (потребители)** - действуют самостоятельно и независимо покупают на рынке товары и услуги, предъявляют на них спрос. |
| **Продавцы (производители)** - предлагают товар и услуги, формируют предложение. |
| **Особенности рынка:** |
| 1. Люди не просто спрашивают и предлагают товары, они обмениваются. Отдают те товары, которые им не нужны или менее нужны и в обмен стремятся получить необходимые товары. |
| **Обмен** - ситуация, когда люди меняются товарами. |
| 2. Важным элементом этих обменных операций являются деньги. |
| **Деньги** – это всеобщий товарный эквивалент, который выражает стоимость всех товаров и служит посредником при их обмене друг на друга. |
| **Специфичность денег** - заключается в абсолютной ликвидности, то есть наивысшей скорости и лёгкости их обмена на другие активы. |

**Виды стоимости денег**

| **Реальная (внутренняя)** - является стоимостью эмиссии (выпуска) денег и включает траты на производство и материал. |
| :--- |
| **Представительная** - отображает степень доверия людей к самим денежным средствам и их эмитенту (по сути, считается рыночным курсом). |
| **Номинальная** - указывается на денежных знаках и является их номиналом. |
| **Полноценные деньги** - когда номинальная стоимость равноценна реальной. |
| **Неполноценные деньги** - когда номинальная цена ниже реальной. |

**Функции денег в экономике:**

| 1. Применяются как инструмент при обмене товаров и услуг. |
| :--- |
| 2. Измеряют ценность, то есть цену любого продаваемого предмета. В форме цены. |
| 3. Служат средством сбережения. Деньгами можно делать накопления, то есть формировать богатство. При этом их изымают из обращения и превращают в ценные активы (объекты недвижимости, ценные бумаги, золото и т. п.), которые сохраняют покупательную способность и противостоят инфляции. |
| Особенностью функции является то, что она реализуется не напрямую деньгами, а через их эквиваленты (ценные бумаги, золото и пр.). |
| 4. Используются в качестве средства платежа. Подобная функция проявляется при продаже товара в кредит и при отложенной оплате услуг. |
| 5. Мировые деньги. Эта функция закреплена за самыми устойчивыми, важными и общепризнанными денежными единицами (доллар, евро, фунт, франк, иена, юань). |

**Основные требования к денежному материалу:**

| **Однородность качества** - все экземпляры выпускаются одинаковыми. |
| :--- |
| **Прочность** - денежный материал должен обладать достаточной прочностью, чтобы долго находиться в обороте, не теряя своей формы. |
| **Сохраняемость** - длительное хранение не должно приводить к потере физико-химических и других свойств. |
| **Объединяемость и делимость** - деньги должны легко размениваться или объединяться в денежные знаки более крупного номинала. |
| **Компактность** - небольшая масса денежных средств должна обладать достаточно высокой стоимостью. |
| **Узнаваемость** - денежные средства должны отличаться быстротой и лёгкостью определения их номинала. |
| **Высокая степень безопасности** - должна присутствовать защита от подделок, хищений и пр. |

**Виды денег:**

| **Наличные** - являются монетами и банковскими билетами (банкнотами и казначейскими билетами). |
| :--- |
| **Безналичные** - средства, хранящиеся на расчётных счетах и депозитах в банках. |
| **Товарные** - обладают собственной ценностью и полезностью (меха, скот, зерно, золото). |
| **Обеспеченные** - могли по требованию обмениваться на товарные деньги. |
| **Фиатные** - могут выполнять функции денег только при поддержке государства, так как сами не имеют ценности. |
| **Кредитные** - специально оформленные долговые обязательства (вексель, чек). |

**Изменение ценности денег**

| **Инфляция** - это когда ценность денег падает и говорят об обесценении денег. |
| :--- |
| **Дефляция** — это когда реальная стоимость товаров снижается из-за того, что реальная цена денег растет. |
| **Номинальные величины** - экономические величины, выраженные в текущих ценах (задолженность по з/п, цены в магазинах, номинальная процентная ставка по депозитам). |
| **Реальные величины** – расчетные экономические величины, выраженные в неизменных ценах (реальная з/п, реальные доходы, реальный ВВП). |

### **Лекция 8. Механизм функционирования рынка**

**Модель спроса и предложения. Крест Маршалла. Спрос. Факторы, влияющие на спрос. Эластичность спроса. Предложение. Факторы, влияющие на предложение. Эластичность предложения. Состояние рынка**

**Модель - Крест Маршалла**

| **Вертикальная ось** – Цена товара – Price (P) |
| :--- |
| **Горизонтальная ось** – Количество товара – Quantity (Q) |
| **Кривая спроса** – нисходящий график (D) |
| **Кривая предложения** – восходящий график (S) |
| **Точка равновесия** - The point of equilibrium (пересечение D и S) |

**Спрос. Факторы, влияющие на спрос**

| **Спрос** – это количество какого-то блага (товара или услуги), которое покупатели готовы купить при данной цене в определенный промежуток времени. |
| :--- |
| **Закон спроса** — величина (объём) спроса уменьшается по мере увеличения цены товара. |
| **Величина спроса является функцией цены товара** Qp= f(P). |
| **Кривая спроса** — это график, иллюстрирующий связь между ценой определенного товара или услуги и количеством товара, которое может и хочет купить потребитель по данной цене. |

Выделяют изменения (1) **величины спроса** и (2) **спроса**.

| **Величина спроса** - это некое конкретное количество, которое готовы покупатели купить при данной конкретной цене. |
| :--- |
| **Изменение величины спроса (движение цены вверх-вниз)** зависит исключительно от ценового фактора. Величина спроса меняется только тогда, когда меняется цена. Выглядит как движение точки по кривой спроса. |
| **Изменение спроса (движение кривой вправо-влево)** означает, что покупатели товара готовы купить меньше (или больше) при любой цене. При этом P – неизменна, а Q – меняется. Зависит от неценовых факторов. |

**Неценовые факторы, влияющие на изменение спроса:**

| (1) **Изменение доходов покупателей** |
| :--- |
| **Нормальный товар** – товар, спрос на который увеличивается по мере роста доходов покупателей (высококачественное продовольствие, бытовая техника, автомобили). Сдвиг вправо при росте доходов. |
| **Низший (инфериорный) товар** - товар, спрос на который падает по мере роста доходов покупателей (лапша быстрого приготовления, углеводные продукты). Сдвиг влево при росте доходов. |
| (2) **Спрос на другие товары** |
| **Товары-субституты** - это взаимозаменяемые товары (чай или кофе, рыба или мясо). Рост цены на рыбу ведет к росту спроса на курицу. |
| **Комплементарные товары** – товары, которые способны удовлетворять потребности покупателей лишь в комплексе с другими (компьютер и ПО, автомобиль и бензин). Рост цены на рыбу ведет к снижению спроса на рыбные приправы. |
| (3) **Информация** |
| **Положительная** (реклама, хорошие отзывы) - спрос увеличивается (сдвиг вправо). |
| **Отрицательная** (плохие отзывы) - спрос уменьшается (сдвиг влево). |
| (4) **Мода, вкусы, обычаи, сезонность** |
| **Мода:** если приходит мода на красный цвет, спрос на красные платья увеличивается, проходит мода - спрос падает. |
| **Сезонность:** Услуги Дедов Морозов (пик перед Новым годом), спрос на лыжи (зимой), спрос на прохладительные напитки (летом). |
| (5) **Ожидания покупателей** |
| **Ожидание подорожания товара** приводит к покупке его сейчас, пока не поздно. Даже если ожидания были ложными, сам факт наличия ожиданий уже может увеличить цену на товар (сдвиг вправо). |
| **Ожидание падения цены** товара приводит к отсрочке покупки (сдвиг влево). |
| **!!! Ожидания самооправдываются количеством покупателей** |

**Эластичность спроса**

| **Эластичность спроса** — показатель степени чувствительности (реакции) потребителей к изменениям цены товара. |
| :--- |
| **Коэффициент эластичности спроса по цене определяется по формуле:** |
| \(K_p^D = \frac{Q_2 - Q_1}{Q_1} \cdot \frac{P_2 - P_1}{P_1}\) |
| Q1 и Q2 - первоначальный и текущий объем спроса |
| P1 и P2 - первоначальная и текущая цена |
| **Коэффициент эластичности спроса по цене всегда принимает отрицательное значение.** |
| > 1 - спрос эластичен (объем меняется больше, чем цена) |
| = 1 - спрос единичен (объем меняется адекватно цене) |
| < 1 - спрос неэластичен (объем меняется меньше, чем цена) |
| **Примеры эластичного спроса:** предметы, у которых много заменителей; предметы роскоши; товары, стоимость которых ощутима для семейного бюджета. |
| **Примеры неэластичного спроса:** товары, у которых мало заменителей (хлеб, соль); предметы первой необходимости (лекарства); товары, стоимость которых незначительна для семейного бюджета (карандаши). |

**Предложение. Факторы, влияющие на предложение**

| **Предложение** — это зависимость количества блага, которое продавцы готовы продать, в зависимости от цены. |
| :--- |
| **Закон предложения** - при прочих неизменных факторах величина предложения увеличивается по мере увеличения цены на товар. |
| **Величина предложения является функцией цены товара** Qs= f(P). |
| **Кривая предложения** — это график, иллюстрирующий связь между ценой определенного товара или услуги и количеством товара, которое может и хочет продать продавец по данной цене. |

Выделяют изменения (1) **величины предложения** и (2) **предложения**.

| **Величина предложения** – это некое конкретное количество, которое готовы продать продавцы при данной конкретной цене. |
| :--- |
| **Изменение величины предложения (движение цены вверх-вниз)** зависит от ценового фактора. Выглядит как смещение точки вдоль кривой предложения. |
| **Изменение предложения (движение кривой вправо-влево)** означает, что продавцы товара готовы продать меньше (или больше) при любой цене. Зависит от неценовых факторов. |

**Неценовые факторы, влияющие на изменение предложения:**

| (1) **Технологические изменения** — более совершенная технология позволяет увеличить предложение (сдвиг вправо). |
| :--- |
| (2) **Цены на ресурсы** - если ресурсы доступнее и дешевле, это увеличит предложение (сдвиг вправо). Если ресурсы станут более редкими и дорогими, это уменьшит предложение (сдвиг влево). |
| (3) **Субсидии и налоги** - субсидирование производителей увеличивает предложение (сдвиг вправо), рост налогов уменьшает предложение (сдвиг влево). |
| (4) **Ожидания продавцов** - если продавцы ожидают, что товар подорожает, они могут придержать продажи (сдвиг влево). Если ожидают падения цен, будут стараться продать побыстрее (сдвиг вправо). |
| (5) **Количество продавцов** - рост количества продавцов приводит к росту предложения (сдвиг вправо). |

**Эластичность предложения**

| **Эластичность предложения** — показатель, воспроизводящий изменения совокупного предложения, которые происходят в связи с ростом цен. |
| :--- |
| **Коэффициент эластичности предложения по цене определяется по формуле:** |
| \(K_p^S = \frac{Q_2 - Q_1}{Q_1} \cdot \frac{P_2 - P_1}{P_1}\) |
| **Коэффициент эластичности предложения по цене всегда положителен.** |
| > 1 - предложение эластично |
| = 1 - предложение единично |
| < 1 - предложение неэластично |
| **Примеры эластичного предложения:** товары роскоши, товары с высокой стоимостью; товары, у которых есть заменители. |
| **Примеры неэластичного предложения:** товары, у которых мало или нет заменителей; рынок скоропортящихся продуктов; редкие предметы роскоши. |

**Задание. При цене продукта P1 = 50 денежных единиц объем его предложения составил 100 единиц. При снижении цены до P2 = 40 денежных единиц объем предложения сократился до 80 единиц. Рассчитайте коэффициент эластичности предложения.**
**Дано:** P1=50, P2=40, Qs1=100, Qs2=80
**Решение:** \(K_p^S = \frac{80 - 100}{100} : \frac{40 - 50}{50} = \frac{-20}{100} : \frac{-10}{50} = -0.2 : -0.2 = 1\)
**Вывод:** Так как K = 1, то предложение единичное.

### **Лекция 9. Предпринимательство как движущая сила экономики**

**Понятие предпринимательства. Организационно-правовые формы. Фирма: общая характеристика.**

**Понятие предпринимательства**

| **Предпринимательство** – инициативная, самостоятельная, осуществляемая на свой риск, под свою имущественную ответственность деятельность граждан, физических и юридических лиц, направленная на систематическое получение прибыли от пользования землей и имуществом, продажи товаров, выполнения работ, оказания услуг (Ст.2 ГК РФ). |
| :--- |
| **Предприниматель** - это субъект предпринимательской деятельности, стремящийся к максимизации своей прибыли, за счет сознательного повышения экономического риска, связанного с вложением в дело собственных средств и принятия на себя имущественной ответственности за результаты хозяйственной деятельности. |
| **Лица, осуществляющие предпринимательскую деятельность,** должны быть зарегистрированы в этом качестве в установленном законом порядке. |
| **Роль предпринимателя в общественном развитии** заключается в постоянном «возмущении» экономики, наполнении ее нововведениями. |
| Такими качествами обладает лишь 5–8 % трудоспособного населения. |
| В развитых странах - доля трудоспособного населения, занятого на работе только в малых и средних фирмах составляет 50–80 %, а производится на этих фирмах 50–70 % всей продукции страны. В России – доля населения, занятая предпринимательством составляет чуть больше 10 %, и примерно такова доля производимого им продукта. |
| **Предприниматель центральная фигура рынка:** организует производство товаров и доводит их до конечного потребителя, уплачивает налоги, содержит государство. |
| **Экономические цели предпринимательства** - получение прибыли. |
| **Неэкономические цели предпринимательства:** 1) внутреннюю потребность реализовать творческие замыслы, 2) получение экономической свободы, 3) повышение социального статуса и престижа, 4) возможность заниматься благотворительностью и меценатством. |
| Ведут к «комфортному состоянию души». |
| **Примеры реализации неэкономических целей предпринимательства:** Э. Карнеги вложил 350 млн. долл. в социальные программы и построил 2000 публичных библиотек. Джон Д. Рокфеллер пожертвовал 550 млн. долл. на социальные цели. Бил Гейтс (компания Microsoft) – 23 млрд. долл. |

**Бизнес** - это самостоятельная, осуществляемая на свой риск деятельность, направленная на получение прибыли от пользования имуществом, продажи товаров, выполнения работ или оказания услуг лицами.

**Задачи бизнеса** состоит в обеспечении согласованной и эффективной работы, а именно: управление персоналом, производством, сбытом, сотрудничеством с партнерами, финансами, связями с государством, общественностью и др.

### **Лекция 10. Поведение фирмы на рынке**

**Ценовая конкуренция на рынке совершенной конкуренции. Типы монополий. Монополия — это хорошо или плохо? Ценовая дискриминация**

**Ценовая конкуренция на рынке совершенной конкуренции**

| **Совершенная конкуренция** - это такое состояние рынка, при котором ни один его участник не имеет возможности оказывать существенное влияние на его функционирование. Продавцам и покупателям приходится подстраиваться к заданным условиям рынка. |
| :--- |
| На рынке совершенной конкуренции методы неценовой конкуренции не эффективны. |
| **Ценовая конкуренция** – конкуренция с помощью снижения цен. На рынке совершенной конкуренции фирмы могут бороться, исключительно снижая издержки и цены. |
| В ситуации крайней ценовой конкуренции она может привести к серьезным потерям благосостояния как общества, так и отдельных фирм. Такой крайний случай ценовой конкуренции получил название **ценовой войны**. |
| **Ценовая война** — экономический термин, который описывает серию последовательных снижений цен на товары или услуги, вызванных острой рыночной конкуренцией. |
| **Пример.** В крупных городах компания Uber контролирует 80% всех поездок. В Москве рынок такси поделен между тремя агрегаторами: от 40% до 50% контролирует «Яндекс.Такси», и по 25–30% — Uber и Gett. Uber был недоволен своей долей и развязал ценовую войну. |

**Типы монополии**

| **Монополия** — это рыночная структура, при которой контроль над определенной отраслью экономики оказывается в руках одного субъекта. Он единолично производит и реализует товар или оказывает услугу. Доступ для других участников рынка оказывается закрыт в силу естественных или искусственно созданных причин. |
| :--- |
| **Искусственная монополия** - это монополия, возникшая временно, в силу воздействия каких-то факторов, основными из которых являются появление научной разработки, единоличное владение лицензией, слияние и поглощение и т.п. |
| **Классическими примерами искусственных монополий в РФ являются Росатом и Роскосмос.** |
| **Естественная монополия** – это фирма, которой выгодно быть крупной за счет эффекта возрастающей отдачи от масштаба. Другая рыночная структура будет неэффективной. |
| **Классическим примером естественной монополии в РФ является РЖД.** |
| **Эффективный размер фирмы** — это объем производства, при котором достигается минимальная себестоимость, минимальные средние общие издержки. У естественных монополий такой эффективный размер настолько большой, что одна фирма с минимальными затратами обеспечивает весь рынок. |
| Где можно увидеть такую ситуацию? В первую очередь в инфраструктурных видах деятельности: транспортировке нефти или газа по трубопроводу, в железнодорожных перевозках, транспорте электроэнергии по линии электропередач. |

**Монополия — хорошо это или плохо?**

| **Доводы «против» монополии** |
| :--- |
| **Довод первый.** Монополист продает по сравнению с конкурентным рынком слишком мало продукции и по слишком высокой цене. Монополизация приводит к потерям общественного благосостояния. |
| **Довод второй.** Считается, что монополистическое производство менее эффективно. Монополист, в спину которого не дышат конкуренты, не заинтересован в повышении эффективности, в снижении себестоимости. |
| **Довод третий.** Монополист может дополнительные ресурсы тратить на поддержание своего монопольного положения. Это приводит к ухудшению работы данного рынка, к потере эффективности. |
| **Доводы «за» монополию** |
| **Довод первый.** Монополии обладают сверхприбылью и могут осуществлять инвестиции в научно-технические разработки, а также единолично воспользоваться плодами нововведений. |
| **Второй довод.** Монополии предоставляют уникальный товар и услуги. |
| **Третий довод.** Монополии реализовывают крупные социальные проекты. |

**Ценовая дискриминация**

| **Ценовая дискриминация** – это продажа одного и того же товара по разным ценам разным покупателям. |
| :--- |
| Почему это может быть выгодно? Если мы установим разные цены для разных покупателей, то с первого покупателя мы получим максимум возможного и второго покупателя мы не потеряем. |
| **Ценовая дискриминация первого рода** (совершенная ценовая дискриминация) |
| Цена устанавливается продавцом каждому покупателю. Если один покупатель готов заплатить много, продавец ему установит более высокую цену. Если покупатель обладает меньшей платежеспособностью, для него будет своя персональная более низкая цена. |
| **Примеры:** восточный базар, персональные услуги (репетитор, няня). |
| **Ценовая дискриминация второго рода** |
| Используют принцип самоотбора. Создаются условия, при которых покупатели делятся на группы сами. |
| **Примеры:** акция «Приходи в красном — получишь скидку!»; сбор купонов для скидки; билеты в бизнес-класс. |
| **Ценовая дискриминация третьего рода** |
| Цена устанавливается продавцом группе покупателей. Одна группа более платежеспособная, другая группа менее платежеспособная. Менее платежеспособной группе предлагаются более низкие цены. |
| **Примеры:** льготные цены для пенсионеров в определенные часы, для студентов, для молодежи; цена для иностранцев в музеях выше, чем для граждан России. |

### **Лекция 12. Олигопольные рынки**

**Модели олигополии. Ценовая война. Модель ломаной кривой спроса. Картель**

**Олигополия** - наиболее распространенная рыночная структура и при этом наиболее сложная для изучения, потому что формы взаимодействия компаний на олигополистическом рынке очень разнообразны.

**Модели поведения олигополий:**
- ценовая война;
- картель;
- модель ломаной кривой спроса;
- лидерство в ценах;
- теория игр.

**Ценовая война** — экономический термин, который описывает серию последовательных снижений цен на товары или услуги, вызванных острой рыночной конкуренцией.

**Пример ценовой войны.** Компания «Трансаэро» и «Внуковские авиалинии» снижают цены на перелеты Москва — Новосибирск, чтобы привлечь к себе больше пассажиров, заполнить свои самолеты, иметь лучшие финансовые показатели, но компания «Сибирь» не остается в долгу и снижает цены на свои перелеты еще сильнее. В ответ «Трансаэро» и «Внуковские авиалинии» опять снижают цены, «Сибирь» отвечает, и дальше вот процесс идет. Процесс ценовой войны зашел между этими компаниями настолько далеко, что они стали прибегать к демпингу.

**Демпинг** — это снижение цен ниже уровня себестоимости. При демпинге компания намеренно идет на убыток, с тем чтобы выгнать с рынка других своих конкурентов. Поэтому в большинстве случаев демпинг запрещен антимонопольным законодательством.

**Модель ломаной кривой спроса**

Суть модели:
Если одна из фирм снижает цены, другие (до определённого предела) последуют за ней, чтобы не потерять покупателей.
Если фирма повышает цены, её конкуренты не делают этого, рассчитывая переманить к себе часть покупателей.

**Пример ломаной кривой спроса**
На американском рынке стали государство повысило уровень налогообложения на производителей стали, и по логике вещей это должно было бы привести к повышению цен, но повышения цен не последовало. Предположим, что у отдельно взятой компании в настоящий момент есть некий объем производства по некоторой цене. Что будет, если в ответ на повышение налогов данная компания повысит цены? Очень большая вероятность, что ее конкуренты цены не повысят. Она одна повысит цены, очень быстро потеряет своих клиентов, которые уйдут к конкурентам, и, соответственно, на повышение цены получит очень сильное падение продаж. Если из этой же точки двигаться в другом направлении, если снижать цену, то эффект будет совершенно другой. Если одна компания снизит цены, то ее конкуренты тоже снизят цены, чтобы не потерять своих клиентов. И в результате на снижение цен реакция спроса будет совершенно другой. Снижение цен не принесет компании большого прироста в количестве клиентов.

**Модель ломаной кривой спроса**
Попытка фирмы снизить цену для расширения своего рыночного сегмента наталкивается на ответную реакцию конкурентов.
**Вверху слева** - линия спроса более пологая – с более высокой эластичностью по цене.
**Внизу справа** — более крутая – с низкой эластичностью по цене.
Двум разным кускам кривой спроса будет соответствовать два разных куска выручки - то есть ломаной кривой предельного дохода MR.

**Картель** – это чаще всего объединение продавцов.
**OPEC** (Organization of Petroleum Exporting Countries), то есть Организация стран-экспортеров нефти – это самый известный картель наднациональный картель.
Картели существуют на наднациональном уровне (легально).
Картели запрещены на национальном уровне.

**Ситуация 1.** Снижение объемов добычи приводит к повышению цены. Участники ОПЕК сокращают добычу нефти, что приводит к росту мировых цен. Этим повышением цен воспользуются все участники картеля.

**Ситуация 2.** Картель при большом количестве участников очень неустойчив и разваливается изнутри, потому что каждый из участников начинает нарушать соглашение. Начинает продавать больше, дешевле, чтобы получить дополнительную выгоду именно для себя.

**Получается странная вещь:** объединение в картель выгодно всем участникам, но все участники начинают обманывать своих коллег по картелю, начинают нарушать соглашение, которое определяет картель, и в результате от этого все страдают.

**Почему так странно получается?** Ответ на этот вопрос дает **теория игр**.

Устойчивыми являются структуры, где фирмы избегают ценовых войн (например, модель ломаной кривой спроса, картель). ### **Лекция 13. Государство в современной экономике: провалы рынка**

**Провалы рынка: монополия, внешние эффекты (способы решения внешних эффектов), общественные блага (свойства общественных благ), асимметричность информации.**

| **«Провалы» рынка** - ситуации, в которых свободное действие рыночных механизмов неспособно обеспечить рациональное распределение и использование ресурсов. |
| :--- |
| **Виды «провалов» рынка:** |
| 1. Разрушение условий конкуренции в результате стихийного развития процесса монополизации. |
| 2. Внешние эффекты. |
| 3. Общественные блага. |
| 4. Асимметричность информации. |

**Провалы рынка: монополии**

| Совершенная (свободная) конкуренция наиболее эффективно распределяет ресурсы рыночной системы и определяет, что и для кого производить с учетом потребностей общества. |
| :--- |
| В ходе конкурентной борьбы слабые, неэффективные производители уходят с рынка, а сильные, напротив, расширяют свое производство и постепенно обретают рыночную власть. |
| В результате создаются условия для возникновения монополий. |
| Монополисты имеют возможность оказывать существенное влияние на цены, ограничивая объемы производства, в некоторых случаях препятствуют внедрению более совершенной технологии. |
| В результате потребители вынуждены платить более высокие цены за приобретаемую продукцию, что ведет к уменьшению их реальных доходов, и доходы монополий растут не за счет повышения эффективности производства, а за счет перераспределения доходов через механизм монопольно высоких цен. |
| Рыночная система начинает неэффективно использовать ограниченные ресурсы. |

**Провалы рынка: Внешние эффекты. Способы решения внешних эффектов**

| **Внешние эффекты** проявляются тогда, когда на производителя влияет поведение третьих лиц или других организаций. |
| :--- |
| **Внешние эффекты не отражаются** в рыночных ценах, которые достаются «третьим лицам», не участвующим в рыночной сделке. |
| **Внешние эффекты делятся** на отрицательные и положительные. |
| **Отрицательные эффекты связаны** с издержками (например, издержки владельцев пансионата из-за дымящего предприятия). |
| **Положительные эффекты связаны** с выгодами для третьих лиц (например, профилактическая прививка снижает вероятность заболеть как у самого человека, так и у окружающих). |
| **Почему внешние эффекты – плохо?** |
| Поскольку часть издержек перекладывается на другие лица или часть полезности блага бесплатно присваивается другими лицами, в экономике возникает неэффективное распределение доходов. |
| **В случае отрицательных эффектов** – объем производства и привлечение ресурсов оказывается избыточным. |
| **В случае положительных эффектов** – недостаточным. |
| **Традиционный подход к решению проблемы внешних эффектов** |
| 1) предложил английский экономист, представитель кембриджской неоклассической школы Артур Сесил Пигу: государство вынуждено вмешиваться, чтобы интернализировать (вменить) внешние эффекты. |
| 2) **Интернализация** - процесс освоения внешних структур, в результате которого они становятся внутренними регуляторами. |
| 3) Наиболее известными (традиционными) мерами государственного вмешательства, направленными на решение интернализации внешних эффектов, являются корректирующие налоги и субсидии. |
| Однако, корректирующие налоги и субсидии не могут решить полностью проблем, возникающих благодаря существованию внешних эффектов. |
| Во-первых, в реальной практике довольно трудно точно исчислить размер вреда и пользы внешних эффектов. |
| Во-вторых, корректирующие налоги, которые платят производители благ, характеризующихся отрицательными внешними эффектами, не всегда достигают поставленной цели. |
| **Рыночный способ решения проблемы внешних эффектов** |
| 1) предложил Рональд Коуз в 1960 году в своей статье «Проблема социальных издержек». |
| 2) **Теорема Коуза** - когда затраты на проведение переговоров ничтожно малы, внешние эффекты могут быть интернализированы путем установления правительством прав собственности на ресурсы и разрешения свободно обменивать эти права. |
| 3) **Пример** - Киотский протокол – определен общий порог выбросов для всех стран и предложено странам, выбрасывающим много вредных веществ, покупать право на выброс у тех стран, которые выбрасывают их мало. |
| **Суть теоремы Коуза** - Если эти права вполне определены и могут покупаться и продаваться на рынке, рыночный механизм может привести стороны к эффективному соглашению. |

**Провалы рынка: Общественные блага. Свойства общественных благ**

| **Частное благо** - блага, которые предназначены для личного потребления. Потребление частного блага одними лицом делает невозможным его потребление другими лицами, не заплатившими за него. |
| :--- |
| **Общественные блага** - потребление общественные блага доступно одновременно многим людям, например, свет маяка в море, оборона, уличное освещение. |
| **Граница между частным и общественным благами** - наличие таких критериев, как конкурентность/неконкурентность и исключаемость/неисключаемость. |
| **Концепция общественных благ (Пол Самуэльсон, 1954)** - есть часть благ, у которых такой большой внешний эффект, который приводит к тому, что люди вне зависимости от того оплатили они это благо или нет потребляют его сообща. |
| Тех, кто не участвовал в оплате блага нельзя отстранить от его потребления, при этом само потребление третьих лиц никак не сказывается на потреблении тех, кто платит. |
| **Свойство общественных благ** - неисключаемость и неконкурентность. |
| **Проблемы безбилетника (фрирайдера)** - поскольку потребители получают выгоды от чисто общественного блага независимо от того, платят они за него или нет, то возникает желание обойтись без лишних выплат, получить это благо даром. |
| В результате, потребители пользуются выгодами, не оплачивая свою долю издержек, связанных с обеспечением этих выгод. |
| **Пример проблемы безбилетника (фрирайдера)** - феномен уклонения граждан от уплаты налогов, идущих на обеспечение общественных благ. |
| **Проблема производства общественных благ решается** государством (производство на государственных предприятиях или через систему государственных закупок за счет налогов). |

**Провалы рынка: асимметричность информации**

| **Асимметричность информации** (неполная информация) — это неравномерное распределение информации о товаре между сторонами сделки. |
| :--- |
| **Классический пример асимметричной информации** дает сфера здравоохранения. Пациент не в состоянии самостоятельно выбрать лучший метод лечения, выбрать нужное лекарство, так как не владеет профессиональной информацией. |
| Неполнота информации, ее неравномерное распределение между покупателями и продавцами ведет к тому, что покупатели и производители могут принимать неверные решения, неэффективно использовать ресурсы. |

### **Лекция 14. Государство в современной экономике: провалы государства**

**Провалы (фиаско) государства: неравенство и несправедливость распределения доходов (оценка уровня дифференциации доходов), низкое качество информации, сложная система сбора информации. Политизация экономических решений, недостаточная мотивация управленческих структур**

| **Провалы (фиаско) государства** - случаи неэффективного распределения и применения общественных ресурсов со стороны государства. |
| :--- |
| **Провал государства: неравенство и несправедливость распределения доходов** |
| 1. **Эгалитарный или «уравнительный» подход** - требует равного распределения доходов. |
| 2. **Роулзианский подход** – допускает неравенства, если они способствуют улучшению положения наименее обеспеченных членов общества. |
| Подход допускает неравенства, если они способствуют улучшению положения наименее обеспеченных членов общества. |
| 3. **Утилитарный подход** - справедливость существует только тогда, когда растет благосостояние всех членов общества. |
| 4. **Рыночный подход** - рынок конкурентен, следовательно все взаимовыгодные торговые сделки рано или поздно будут заключены, а возникающее в итоге равновесное распределение ресурсов окажется экономически эффективным и справедливым. |

**Оценка уровня дифференциации доходов**

| **Доходы населения** – это совокупность денежных и натуральных средств, полученных за определенный период населением и предназначенных для потребления и сбережения. |
| :--- |
| **Инструменты измерения:** |
| - децильный коэффициент; |
| - кривая Лоренца; |
| - коэффициент Джини. |
| **Децильный коэффициент** - показатель, используемый в социальной статистике для оценки дифференциации населения по доходам (расходам, потреблению). |
| - основан на сравнении доходов двух противоположных групп населения — высокодоходной и низкодоходной. |
| - рассчитывается как отношение 9-го дециля (10% населения с наибольшими доходами) к 1-му децилю (10% населения с наименьшими доходами). |
| - разрыв в доходах в обществе, превышающий 10 раз, считается опасным для социальной стабильности. |

**Пример: 1995 год. ДК Москва = 28; ДК ЦЧР = 7**

**Кривая Лоренца**
Для построения кривой Лоренца все население в зависимости от уровня доходов разбивается на 5 групп (квинтели).
**Первая группа** - 20% семей с наименьшими доходами.
**Пятая группа** - 20% семей с наибольшими доходами.
График отражает долю дохода, приходящуюся на различные группы населения сформированные на основании размера дохода, который они получают (нарастающим итогом).

Первые 20% населения могут получать 5% доходов, 40% населения — 15% доходов, 60% населения — 35% доходов, 80% населения — 60% доходов, и 100% населения — 100% доходов.

**Кривая Лоренца или Лук Лоренца** – это вид графика. Чем лук сильнее натянут, тем выше в стране неравенство доходов.
**Абсолютное равенство (ОЕ)** наблюдается тогда, когда первая группа имеет такой же совокупный доход, как и пятая.
**Абсолютное неравенство (FE)** наблюдается тогда, когда весь совокупный доход приходится на одного человека.

Построение кривой Лоренца происходит путем соединения точек, отражающих процент доходов и долю населения нарастающим итогом.

| 2 группа | 20% | 40% | 15% | 20% |

| 4 группа | 20% | 80% | 25% | 70% |
| 5 группа – самые богатые | 20% | 100% | 30% | 100% |

**Коэффициент Джини** — статистический показатель степени расслоения общества данной страны или региона по какому-либо изучаемому признаку.

**Индекс Джини** — процентное представление этого коэффициента.

Используется для оценки экономического неравенства.

Рассчитывается по формуле: как отношение площади фигуры, образованной кривой Лоренца и прямой равенства, к площади треугольника, образованного прямой равенства и осями. G = S1/(S1+S2)

Изменяется от 0 до 1, где 0 – абсолютное равенство, 1 – абсолютное неравенство.

0 - абсолютное равенство.
1 - абсолютное неравенство.

Однозначного взгляда на то, к какому уровню неравенства доходов следует стремиться нет.

Если неравенство доходов будет очень высоким, это подрывает социальную стабильность.
Но, если доходы распределяются очень равномерно, то теряется стимул получать высокие доходы.

**Дж. Кейнса:** «приходится выбирать между неравным распределением доходов или равным распределением нищеты».
Он имел ввиду, что если распределять поровну, то все будут одинаково нищими, никто не захочет хорошо работать.

Каждая страна для себя ищет свою золотую середину.

**Наблюдение** – в Соединенных Штатах неравенство доходов выше, в Германии неравенство доходов значительно меньше. А это страны с достаточно развитой экономикой.

**Способы перераспределения доходов:**
1. Изъятие излишних доходов у богатых (прогрессивная система налогообложения).
2. Распределение средств в большей степени малоимущим через дотации, субсидии, пособия.
3. Подход, основанный на социальных лифтах (создание условий для того, чтобы бедные стали богатыми).

**Иные провалы (фиаско) государства:**
1. Недостаток информации и/или низкое качество информации, исходя из которой принимаются решения.
2. Сложная и многозвенная система сбора информации, принятия решения, доведения его до исполнителя и контроля исполнения решения.
3. Политизация экономических решений.
4. Недостаточная мотивация управленческих структур.
5. Прогноз последствий экономических решений, принимаемых государством, зачастую невозможен.

### **Лекция 15. Национальная экономика**

**Национальная экономика как социально-экономическая система. Методы подсчета ВВП. Дефлятор ВВП. Мультипликаторы сбережения и потребления.**

**Национальная экономика как социально-экономическая система**

| **Национальная экономика (в широком смысле)** - это социально-экономическая система, объединенная общей территорией, государственным устройством, правовыми институтами, единым рынком, культурой и языком. |
| :--- |
| **Национальная экономика (в узком понимании)** - это единый комплекс взаимосвязанных отраслей, сформированных в результате общественного разделения труда, научно-технического развития, международного сотрудничества. |
| **Существенные элементы национальной экономики:** производство, распределение, обмен и потребление материальных благ, услуг и других материальных и нематериальных ценностей. |
| Измерение происходит с использованием обобщающих показателей, позволяющих анализировать общие тенденции развития национальной экономики. |
| **Совокупный общественный продукт** - весь продукт, произведенный в стране в течение года. |
| **Первая часть** – промежуточный продукт, предназначенный для дальнейшей переработки (уголь, сахар, строительные материалы и т.п.). |
| **Вторая часть** - готовые изделия, предназначенные для потребления (автомобиль, станки, оборудование). |
| Разделение совокупного общественного продукта на две части связано с проблемой "двойного счета", возникающей при оценке объема выпуска по общему потоку товаров. |
| **Проблема двойного счета** - суммирование промежуточной и конечной продукции приводит к переоценке объемов производства вследствие того, что издержки производства включаются в него несколько раз. |
| **Пример:** Срубленный лес применяется в деревообрабатывающей промышленности для изготовления досок, которые входят в производственный процесс мебельной фабрики, мебельная фабрика изготавливает мебель, продажа которой осуществляется через магазины. Складывание результатов производства на каждом этапе приводит к двойному счету. |
| Проблему "двойного счета" снимает **ВВП**. |
| **ВВП** — макроэкономический показатель, отражающий рыночную стоимость всех конечных товаров и услуг, произведённых за год во всех отраслях экономики на территории конкретного государства для потребления, экспорта и накопления, вне зависимости от национальной принадлежности использованных факторов производства. |
| **Оценивает** производство только конечной продукции, имеющей денежную оценку и произведенной на территории страны. |
| **Не учитывает:** |
| 1) конечную продукцию произведенная домохозяйством для внутреннего потребления; |
| 2) финансовые сделки и сделки, связанные с перепродажей продукции (продажа ценных бумаг, подержанного автомобиля). |

**Методы расчета ВВП**
Существуют три основополагающих метода определения ВВП.

**(1) Производственный метод** - ВВП определяется как сумма произведенной фирмами добавленной стоимости.
**Добавленная стоимость** - это разность между объемами продаж фирм и их закупками материалов и услуг у других фирм.

**Задача. Учет ВВП производственным методом**
Стоимость шерсти – 1000 (произведено в РФ)
Стоимость ткани – 5000 (произведено в РФ)
Стоимость костюма – 10000 (произведено в РФ)
**Определите: ВВП, СОП - ?**
**Решение:**
1) 1000 - 0 = 1000 (добавленная стоимость шерсти)
2) 5000 - 1000 = 4000 (добавленная стоимость ткани)
3) 10000 - 5000 = 5000 (добавленная стоимость костюма)
4) ВВП = 1000 + 4000 + 5000 = 10000
5) СОП = 1000 + 5000 + 10000 = 16000

**Задача. Учет ВВП производственным методом**
Стоимость шерсти - 1000 (произведено в Узбекистане)
Стоимость ткани - 5000 (произведено в РФ)
Стоимость костюма - 10000 (произведено в РФ)
**Определите: ВВП, СОП - ?**
**Решение:**
1) 0 (шерсть произведена не в РФ)
2) 5000 - 1000 = 4000 (добавленная стоимость ткани)
3) 10000 - 5000 = 5000 (добавленная стоимость костюма)
4) ВВП = 4000 + 5000 = 9000
5) СОП = 1000 + 5000 + 10000 = 16000

**(2) Учет ВВП на основе потока доходов.**
ВВП = Национальный доход + амортизация + косвенные налоги — субсидии — чистый факторный доход из-за границы.
Где Национальный доход = заработная плата + арендная плата + процентные платежи + прибыль корпораций.

**(3) Учет ВВП на основе потока расходов.**
ВВП = Потребительские расходы + инвестиции + государственные закупки + чистый экспорт.
Y = C + I + G + Xn, где Xn = Ex - Im.

**Задача. Учет ВВП на основе потока расходов**
Личные потребительские расходы увеличились на 100 ден.единиц,
Валовые инвестиции увеличились на 70 ден.единиц,
Государственные расходы сократились на 20 ден.единиц,
Объем экспорта не изменился,
Объем импорта сократился на 10 единиц.
**Определите: ВВП - ?**
**Решение:**
ВВП = 100 + 70 - 20 + (0 - (-10)) = 160 ден. единиц.

**Дефлятор ВВП**

| **Номинальный ВВП** - это ВВП, в составе которого стоимость товаров и услуг измерена в текущих ценах. |
| :--- |
| **Реальный ВВП** - это ВВП, измеренный в постоянных ценах, скорректированный с учетом инфляции. |
| **Дефлятор ВВП** показывает, как изменились цены на продукцию, произведенную в данном году по сравнению с базовым годом. |
| **Дефлятор** = (Номинальный ВВП / Реальный ВВП) * 100% |

**Задача. В стране в 2021 году годовой уровень инфляции составил 5%, за тот же период реальный ВВП вырос на 2,5%. Что произошло с номинальным ВВП страны?**
**Дано:** Дефлятор = 1,05, ВВП реальный = 1,025.
**Найти:** ВВП номинальный - ?
**Решение:**
1) Дефлятор = (ВВПн / ВВПр) * 100
2) 1,05 = ВВПн / 1,025
3) ВВПн = 1,025 * 1,05 = 1,07625 или 107,625%
**Ответ:** Номинальный ВВП вырос на 7,625%.

**Мультипликаторы сбережения и потребления**

| **Спросоограниченная экономика** - это экономика, в которой спрос определяет масштабы вовлечения в оборот экономических ресурсов. |
| :--- |
| В спросоограниченной экономике существует проблема недоиспользования экономических ресурсов (безработицы, недогрузки мощностей). |
| Общественное производство не достигает границы производственных возможностей, весь ресурсный потенциал не используется. |
| **Полная занятость ресурсов** - это занятость, экономически выгодная основным хозяйствующим субъектам в данный момент времени. |
| В экономике полная занятость ресурсов достигается даже тогда, когда какая-то их часть остается вне производства, в состоянии между производствами (переналадка оборудования, естественная безработица). |
| **Потребление** - это расходы на конечные товары и услуги, купленные в целях получения удовлетворения или насыщения потребностей посредством их использования. |
| **Сбережения** - это та часть располагаемого дохода, которая не потребляется. |
| **Факторы, определяющие уровень потребления и сбережения в национальной экономике:** богатство; рост уровня цен; ожидание роста цен; ожидание роста доходов; потребительская задолженность; налогообложение. |
| Пропорции накопления и потребления влияют на рост Национального дохода. Для расширенного воспроизводства норма накоплений (инвестиций) должна быть выше 25%. |

**Мультипликативный эффект** - показывает механизм распространения на всю экономику любых изменений.
Он измеряет влияние, какое изменение экономической активности — например, инвестиций или расходов—окажет на общий объем производства чего-либо.
**Причины мультипликации** - расходы одних хозяйствующих субъектов являются доходами других хозяйствующих субъектов.
Изменение дохода влияет на изменения доли потребления и накопления в национальном доходе.

**Предельная склонность к потреблению МРС** показывает, какая часть дополнительного дохода направляется на потребление.
МРС = ΔC / ΔY = прирост потребления / прирост дохода.

**Предельная склонность к накоплению MPS** показывает, какая часть дополнительного дохода направляется на сбережения.
MPS = ΔS / ΔY = прирост сбережений / прирост дохода.

При этом MPC + MPS = 1.

**Задача. Мультипликативный эффект сбережений**
**Дано:**
Объем сбережений в позапрошлом году составил 8200 ден.единиц
Объем сбережений в прошлом году составил 8550 ден.единиц
Предельная склонность к сбережению - 0,2
**Найти:** Прирост располагаемого дохода - ?
**Решение:**
MPS = ΔS / ΔY
0,2 = (8550 - 8200) / ΔY
0,2 = 350 / ΔY
ΔY = 350 / 0,2 = 1750 ден. единиц.

**Задача. Мультипликативный эффект потребления**
**Дано:**
Объем потребления в позапрошлом году составил 30000 ден.единиц
Объем потребления в прошлом году составил 40000 ден.единиц
Предельная склонность к потреблению - 0,8
**Найти:** Прирост располагаемого дохода - ?
**Решение:**
МРС = ΔC / ΔY
0,8 = (40000 - 30000) / ΔY
0,8 = 10000 / ΔY
ΔY = 10000 / 0,8 = 12500 ден. единиц.

### **Лекция 16. Перегрев национальной экономики: риски и возможности**

**Экономический цикл. Механизм колебаний. Модификация экономических колебаний. Антициклическое регулирование.**

**Экономические циклы**

| **Долгосрочные факторы, вызывающие цикличность:** демографические, технологические и другие. |
| :--- |
| **Краткосрочные факторы, вызывающие цикличность:** уровень потребления, уровень сбережений и объем инвестиций. |
| **Экономические циклы** — колебания экономической активности, состоящие в повторяющихся экономических спадах (рецессии, депрессии) и экономических подъёмах. |
| **Циклы носят** периодический, но не регулярный характер. Продолжительность и амплитуда колебаний могут сильно меняться. |
| **Продолжительность и амплитуда** колебаний могут сильно меняться. |
| **Основные модели циклов:** четырехфазная и двухфазная. |

**Четырехфазная (классическая) модель**
Выделяют четыре фазы: спад (АВ), депрессия (ВВ), оживление (ВА1), подъем (А1А2).

**Двухфазная модель**
Выделяют верхнюю и нижнюю поворотные точки цикла: Пик (В, F) и Дно (D). Движение между данными точками происходит посредством Сокращения (BD) и Подъема (DF).

**Формы экономических циклов:**
1) сходящиеся (затухающие) – уменьшающаяся со временем амплитуда;
2) расходящиеся (взрывные) – увеличивающаяся амплитуда;
3) постоянные – стабильная амплитуда.

**Основные виды экономических циклов**

| **Циклы Дж. Китчина (циклы запасов)** - краткосрочные колебания (2-4 года), обусловленные жизненным циклом товара. |
| :--- |
| **Циклы К. Жюглара** - среднесрочные колебания (7-11 лет), связаны с периодичностью обновления основного капитала, с взаимодействием денежно-кредитных факторов. |
| **Кризисы РФ (триггеры):**<br>1998 – дефолт государственных ценных бумаг.<br>2008 – мировой ипотечный кризис.<br>2020 – пандемия COVID. |
| **Циклы К. Маркса** - колебания в 10 лет, связанные с периодичностью массового обновления основного капитала. |
| **Циклы С. Кузнеца (строительные циклы)** - колебания (15-20 лет), связанные с периодичностью обновления жилищ и некоторых видов производственных сооружений. |
| **Циклы Н. Кондратьева – большой конъюнктуры (48-55 лет)**<br>1. Промышленная революция в Англии (с конца 80-х гг. XVIII в. до 1844-1851 гг.).<br>2. Развитие железнодорожного транспорта (с 1844-1851 гг. до 1890-1896 гг.).<br>3. Внедрение электроэнергии, радио и телефона (с 1890-1896 гг. до 1939-1945 гг.).<br>4. Автомобилестроение (с 1939-1945 гг. до 1982-1985 гг.).<br>5. Электроника, микропроцессоры и генная инженерия (с 1982-1985 гг.). |

**Почему возникают колебания?**

| **Первый подход - Детерминистический** – Экономический цикл имеет внутреннюю причину. Причиной циклов являются предсказуемые факторы, которые носят систематический характер (вовлечение в хозяйственный оборот новых ресурсов, изменения их структуры, рост потенциала экономики). |
| :--- |
| **Второй подход – Стохастический** – причиной циклов являются случайные факторы, которые нарушают текущее состояние экономики извне и раскачивают экономическую систему (экзогенные факторы). |

**Типы шоков:**
**Шок предложения** – колебания мировых цен на сырье; природные катаклизмы; важнейшие изобретения и открытия.
**Шок спроса** – изменения инвестиционных или потребительских расходов, вызванные изменениями в ожиданиях экономических субъектов.
**Политические шоки** - изменения в макроэкономической политике (изменения в предложении денег, фискальной и валютной политики).

**Комплексные причины экономической цикличности:**
**Индустриальная причина** – инновации, технологические сдвиги.
**Предпринимательская причина** – деловая активность зависит от величины прибыли.
**Рыночная причина** – изменения в реальном производстве проявляются в колебаниях цен и влияют на деловую активность.

**Экономические индикаторы экономической цикличности:**
**проциклические** – параметры возрастают в фазе подъема и сокращаются в фазе спада (совокупный ВВП, денежные агрегаты, уровень цен).
**контрциклические** – параметры во время подъема сокращаются, а во время спада увеличиваются (безработица, число банкротств).
**ациклические** – динамика не связана с какими-либо фазами экономического цикла (объем экспорта).

**Неэкономические индикаторы (триггеры) экономической цикличности:**
**природные** – засухи, наводнения, землетрясения;
**политические** – войны, революции;
**демографические** – эпидемии.

**Механизм колебаний**

**Подъем (оживление)** — рост производства и занятости населения.
(1) При невысокой инфляции повышается спрос, так как потребители стремятся совершить покупки, отложенные во время предыдущего кризиса.
(2) Наблюдается рост выручки и прибыли компаний.
(3) Это приводит к росту инвестиций компаний.
(4) Инвестиционные проекты быстро окупаются.
Национальная экономика сама себя "подогревает": спрос рождает предложение, увеличение которого создает новые доходы и новый спрос.

**Пик** — высшая точка экономического роста, характеризуется максимумом деловой активности.
(1) Производственные мощности работают максимально эффективно. Происходит насыщение инвестиционного и потребительского спроса.
(2) Уровень безработицы очень мал или практически отсутствует.
(3) Это ведет к стабилизации цен, стабилизации прибыли, высокой занятости ресурсов и растущим издержкам производства.
(4) Обычно усиливается инфляция, поскольку рынок насыщается товарами и растет конкуренция.
(5) Срок окупаемости проектов увеличивается, бизнес берет все больше долгосрочных кредитов, возможность погашения которых снижается.
(6) Сокращается инвестиционный спрос и через эффект мультипликатора распространяется на всю экономику, в которой начинается общий спад производства.
(7) Начинается спад.

**Спад** — снижение деловой активности, объемов производства и уровня инвестиций, ведущее к росту безработицы.
(1) Наблюдается перепроизводство товаров.
(2) Цены резко падают.
(3) Вследствие этого снижается объем производства.
(4) Что ведет к росту безработицы.
(5) Это вызывает снижение доходов населения.
(6) Происходит сокращение платежеспособного спроса.
(7) Что еще больше влияет на сокращение объемов производства.

**Депрессия** — низшая точка деловой активности, характеризуется минимальным уровнем производства и максимальной безработицей.
(1) В этот период производится избыток товаров (часть по низким ценам, часть просто портится).
(2) Падение цен прекращается.
(3) Объемы производства немного увеличиваются, но торговля пока протекает вяло.
(4) Капитал, не найдя применения в сфере торговли и производства, стекается в банки.
(5) Это увеличивает предложение денег и ведет к снижению процента по кредитам.
(6) Стабильные и низкие цены, низкий банковский процент делают инвестиции выгодными.
(7) Оживление проявляется в медленном росте производства, вызванном ростом инвестиций.

**Модификация экономических колебаний**
Изменения, которые подорвали свободу движения цен и автоматизм поворотов:
(1) Сформировались субъекты, которые получили контроль над ценами.
(2) Крупные корпорации, получив рыночную власть, смогли воспрепятствовать свободному движению цен.
(3) Деятельность профсоюзов привела к послевоенному стабильному росту заработной платы во всех фазах цикла.
(4) Рост государственных расходов ведет к хроническому дефициту госбюджета и росту государственного долга.
(5) Инфляция становится хронической.
(6) Рост цен не прекращается в ходе спада, а только замедляется.

**Антициклическое регулирование**

| **Фискальная политика** - это политика воздействия на совокупный спрос путем регулирования государственных расходов и доходов. |
| :--- |
| **Кризис:** увеличение государственных расходов и снижение налогов в интересах стимулирования производства. |
| **Подъем:** снижение государственных расходов и увеличение налогов в интересах сдерживания инфляции. |
| **Денежно-кредитная политика** - это политика воздействия на совокупный спрос через регулирование объемов денежной массы и величины процентной ставки. |
| **Кризис:** увеличение денежной массы и снижение процентной ставки в интересах стимулирования совокупного спроса. |
| **Подъем:** сокращение объемов денежной массы и увеличение ставки процента как меры антиинфляционного воздействия. |

Чрезмерное регулирование национальной экономики со стороны государства ведет к появлению **стагфляции**.
**Стагфляция** - это такое состояние экономики, когда застой в производстве сопровождается высоким уровнем безработицы и высокой инфляцией. Одновременное повышение уровня безработицы и уровня цен.
**Причины стагфляции:** монополизация экономики, ведущая к хронической инфляции; "нефтяной шок", вызвавший высокую инфляцию издержек; активное антициклическое регулирование экономики, проводимое государством в развитых странах.
**Основные компоненты экономической политики, позволяющей преодолеть стагфляцию:**
1. Антиинфляционная политика спроса.
2. Политика прямого воздействия на предложение.
3. Регулируемое формирование новых рыночных институтов.
